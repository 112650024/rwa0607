## 投影片 2 ｜ 商業情境(題目七)
金融機構希望把不動產、債權、**股票**等資產上鏈,以提高流動性與投資可及性,但面臨兩大痛點:
1. **估值不透明**:資產缺乏即時、可驗證的公允價格。
2. **流動性受限**:傳統交易受時段、單位(整股)、跨境與結算 T+2 限制。

FormosaX 以**台股**為切入點(資料公開、估值基準明確、最易驗證),示範一套可複製到其他資產類別的「代幣化 + 預言機 + AI 估值 + DeFi」完整堆疊。

## 投影片 3 ｜ 1. 遇到什麼問題(Pitch ①)
**台股投資與資產流動性的結構性痛點:**
- ⏰ **僅限盤中**:09:00–13:30 才能交易,夜間/假日無法即時反應國際盤。
- 🧱 **單位門檻**:一張(1,000 股)門檻高;零股流動性低、撮合慢。
- 🌏 **跨境困難**:外國投資人開戶/換匯/稅務繁瑣,進場成本高。
- 🧾 **估值與擔保不透明**:散戶難即時驗證標的公允價值與背後擔保。
- 🔗 **無法進入 DeFi**:持股不能直接拿來質押借貸或組合應用。

**結論**:台股是高品質資產,卻被「時段 × 單位 × 國界 × 結算」鎖住流動性。

## 投影片 4 ｜ 2. 解決方案(Pitch ②)
**FormosaX = 代幣化交易所 + 預言機估值 + AI 估值/風險 + DeFi + 受監管穩定幣**(均已上鏈)
1. **代幣化台股(ERC-20)**:每檔台股 1:1 對應一個代幣(dTSMC、dMTK…),工廠量產、可碎片化(可買 0.01 股)。
2. **預言機即時估值**:Chainlink AggregatorV3 風格 `PriceOracle`,鏈下餵入 TWSE 收盤/即時價,鑄造/贖回依即時價結算。
3. **AI 輔助估值與風險(題目七核心)**:回歸模型預測公允價與風險分數,動態調整借貸 LTV/清算線,並驅動「動態估值 Dashboard」。
4. **受監管 TWD 穩定幣**:對標金管會《穩定幣專法》草案 — 100% 儲備證明、發行人揭露、贖回權、凍結/暫停、角色分權。
5. **DeFi 應用**:質押台股代幣借 TWD(`LendingPool`)、代幣化新股認購(`StockIPO`,超額 pro-rata 配額)。

> 使用者需求:零股可及、24/7、即時可驗證估值、可進 DeFi、合規可信。以上**全部已實作並部署於 Sepolia**。

## 投影片 6 ｜ AI 輔助估值與風險模型(題目七重點)
**(1) 公允估值 — 回歸模型(資產價格預測)**
- 特徵:歷史價量、技術指標(MA/波動度)、產業/大盤連動、(進階)財報因子。
- 模型:線性回歸 / 隨機森林 → 預測 T+1 **公允價區間**,作為「公允估值參考線」疊在預言機市價上。
- 用途:標示「市價 vs 公允價偏離度」,提醒高估/低估;贖回/清算採保守估值。

**(2) 風險評分 — 動態風控**
- 風險因子:波動度、流動性、抵押集中度 → 0–100 風險分數。
- 連動:把分數餵給 `LendingPool`,**動態調整 LTV / 清算線**(目前固定 50% / 65% → AI 版逐標的浮動)。

**(3) 動態估值 Dashboard**
- 即時市價 vs AI 公允價、風險熱力圖、抵押健康度、儲備覆蓋率,全部讀自鏈上 view function。

> 落地路徑:鏈下 Python 訓練/推論 → 簽章 → 以 Chainlink Functions 將「公允價/風險分數」寫上鏈,供合約引用(現階段 Demo 以預言機價 + 規則風控示範,AI 模組為加值層)。

## 投影片 11 ｜ Tokenomics Canvas
- **代幣名稱與定位**:`dXXXX`(如 dTSMC)= 代幣化台股,1 代幣 ↔ 1 股經濟權利;`TWD` = 平台計價穩定幣。
- **背後資產與來源**:台灣上市股票,價格來源 TWSE(預言機餵價);商轉以實股 1:1 託管擔保。
- **鑄造/銷毀(Mint/Burn)**:存入 TWD 依預言機即時價 `mint`;`redeem` 反向贖回並燒毀;穩定幣 `mintTWD`/`requestRedemption`。
- **發行量與增發規則**:無固定上限,供給隨「TWD 抵押鑄造」彈性增減,恆等於儲備擔保量。
- **權限角色**:`DEFAULT_ADMIN/issuer`、`ATTESTOR`(儲備簽證)、`COMPLIANCE`(凍結/暫停)、工廠 `owner`。
- **費用結構**:Demo 免交易費;商轉可開鑄造/贖回費、AUM、借貸利差、IPO 承銷費。
- **二級市場與流動性**:平台內 mint/redeem 提供基礎流動性;未來上 DEX(AMM)+ 做市;`LendingPool` 釋放抵押流動性。

## 投影片 13 ｜ Smart Contract Role Map
**系統合約(皆已部署 + Etherscan 驗證)**

**角色 → 權限**
| 角色 | 權限 |
|---|---|
| `DEFAULT_ADMIN` / issuer | 發行、設定揭露、`issue` |
| `ATTESTOR` | `attestReserves` 簽署儲備證明 |
| `COMPLIANCE` | `setFrozen`、`pause/unpause` |
| `owner`(工廠/借貸/IPO) | 上架代幣、設風險參數、建立 IPO |
| feeder | `updatePrices` 餵價 |

- **可升級性**:現為不可升級(降低信任風險、易審計);路線圖評估 UUPS Proxy,升級權交多簽/時間鎖。

- **簽名轉移(permit)**:路線圖支援 ERC-2612 `permit`(免 gas 授權,優化 UX)。
- **事件與透明性**:`Minted/Redeemed/PriceUpdated/ReserveAttested/AddressFrozen/Borrow/Liquidate/...` 全上鏈,可於 Etherscan 稽核。
